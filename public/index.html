How Model Security & Access Works:

  • Master Platform Keys: Shoora Tether's enterprise API keys are safely held on the central backend server (shooratetherbackend/.env). The raw key is never exposed to the client or browser.
  • Tier Verification: When a user invokes AI in Desktop IDE, the request passes through /api/ai/agent-chat with the user's JWT token. Backend queries StackCP DB to confirm active pro status before approving requests.
  • Admin Model Control: Any tier upgrade in this admin dashboard immediately unlocks the pro models on the user's Desktop IDE without requiring software reinstall.
